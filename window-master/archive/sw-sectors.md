Window Master: Sliding Window Game Curriculum

Sector 1: Maximum Sum – Fixed Window (Basics)
Concept: Intro to brute force vs. efficient method, fixed-size sum.
Level 1: Maximum sum of 3 consecutive numbers.


Level 2: Maximum sum of 2 consecutive numbers in a small array.


Level 3: Maximum sum of 5 consecutive numbers in a larger array.


Level 4: Array with negative numbers (reinforce handling of negatives).


Level 5: Very large array (emphasize time complexity difference).


👉 Learner outcome: Understand the core intuition of reusing sums.

Sector 2: Minimum Sum – Fixed Window
Concept: Same as Sector 1, but focuses on minimum sums.
Level 1: Minimum sum of 2 consecutive elements.


Level 2: Minimum sum of 3 consecutive elements.


Level 3: Mixed positive/negative numbers.


Level 4: Edge case with repeating numbers (all identical).


Level 5: Large dataset to reinforce efficiency.


👉 Learner outcome: Learners see sliding window works for both “max” and “min” problems.

Sector 3: Variable Window – Target Sum
Concept: Window expands/contracts until a condition is met.
Level 1: Smallest subarray length with sum ≥ target (classic).


Level 2: Largest subarray length with sum ≤ target.


Level 3: Introduce zeros and negatives.


Level 4: Tight constraint target (forces shrinking and expanding).


Level 5: High target (forces exploration of entire array).


👉 Learner outcome: Introduce dynamic window sizing.

Sector 4: String Problems – Distinct Characters
Concept: Apply sliding window to strings, not just numbers.
Level 1: Longest substring without repeating characters.


Level 2: Longest substring with at most 2 distinct characters.


Level 3: Longest substring with exactly K distinct characters.


Level 4: Case sensitivity (mix of uppercase/lowercase).


Level 5: Very long string (performance impact).


👉 Learner outcome: Generalize sliding window beyond arrays.

Sector 5: Maximum/Minimum in Dynamic Window
Concept: Add complexity by tracking extreme values within windows.
Level 1: Maximum element in every window of size K.


Level 2: Minimum element in every window of size K.


Level 3: Combination of both (max & min).


Level 4: Array with duplicates (ties).


Level 5: Very large array, K is large.


👉 Learner outcome: Understand auxiliary data structures (deque/heap).

Sector 6: Multiple Arrays
Concept: Compare across arrays.
Level 1: Maximum sum subarray of size K across two arrays.


Level 2: Minimum difference between two windows (one from each array).


Level 3: Synchronizing sliding windows across arrays of different lengths.


Level 4: Handling negative values in comparisons.


Level 5: Performance with large arrays.


👉 Learner outcome: Handling parallel sliding windows.

Sector 7: Nested Windows
Concept: Sliding windows inside sliding windows (advanced).
Level 1: Average of sums of subwindows.


Level 2: Sliding window applied to results of another sliding window.


Level 3: Tracking maximum of minimums (nested).


Level 4: Tracking minimum of maximums (nested).


Level 5: Large dataset with nested constraints.


👉 Learner outcome: See composability of sliding window.

Sector 8: Edge Cases & Pitfalls
Concept: Practice resilience.
Level 1: Empty array (what should happen?).


Level 2: Window size = 1 (trivial case).


Level 3: Window size = array length (only one window).


Level 4: Window size > array length (invalid case).


Level 5: All elements identical.


👉 Learner outcome: Develop robust implementations.

Sector 9: Large Data / Performance
Concept: Focus on complexity.
Level 1: Array length = 100,000 (measure brute force inefficiency).


Level 2: Compare runtime of brute force vs. sliding window explicitly.


Level 3: Memory constraints (streaming input).


Level 4: Sliding window with very large K.


Level 5: Sliding window with very small K on huge array.


👉 Learner outcome: Appreciate why O(n) matters in practice.

Sector 10+: Master Challenges
Concept: Mix and match.
Level 1: Smallest substring containing all characters of a set.


Level 2: Longest substring with exactly K distinct vowels.


Level 3: Sliding window median (advanced with heaps).


Level 4: Sliding window + prefix sums hybrid.


Level 5: Competitive programming challenge (timed).


👉 Learner outcome: Become experts — ready for real-world interviews.
