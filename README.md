## 🚀 What is DSAG?

DSAG (Data Structures & Algorithms as Games) transforms computer science education by making algorithmic thinking accessible, engaging, and mastery-oriented through game-based learning.

### The Problem We Solve

- **LeetCode Grind**: 4 years to become mediocre at artificial puzzles
- **Poor Learning UX**: Binary pass/fail with no educational feedback
- **AI Cheating**: Text-based assessments are easily automated
- **Irrelevant Content**: Problems don't reflect real job requirements

### Our Solution

**Games are the most powerful learning machines.** We've built interactive games that teach:

- 🚀 **Two-Pointer Technique** - Cosmic Rift Scanners
- 🔄 **Recursion & Call Stack** - Recursionauts  
- 🎯 **Binary Search** - The Enigma Protocol
- 👨‍🍳 **Bubble Sort Algorithm** - The Bubble Sort Chef

## 🎮 Games Overview

### 1. Cosmic Rift Scanners
**Algorithm**: Two-Pointer Technique  
**Theme**: Space exploration with scanner technology  
**Learning**: Finding pairs in sorted arrays efficiently  

### 2. Recursionauts
**Algorithm**: Recursion & Call Stack  
**Theme**: Deep space exploration with recursive navigation  
**Learning**: Understanding recursive thinking and stack behavior  

### 3. The Enigma Protocol
**Algorithm**: Binary Search  
**Theme**: WWII code-breaking and decryption  
**Learning**: Efficient search in sorted data  

### 4. The Bubble Sort Chef
**Algorithm**: Bubble Sort  
**Theme**: Kitchen and cooking management  
**Learning**: Bubble Sort algorithm with interactive decision-making  

## 🚀 Getting Started

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/Triumph-KT/DSAG-V0.git
   cd DSAG-V0
   ```

2. **Open in browser**
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Or simply open index.html in your browser
   ```

3. **Start playing!**
   - Navigate to any game from the main menu
   - Complete levels to unlock achievements
   - Track your progress in the platform

### Deployment

The site automatically deploys to GitHub Pages on every push to main branch.

## 🎯 Educational Philosophy

### Game-First Learning
Every algorithm is taught through interactive gameplay where students make strategic decisions, not just watch automated processes.

### Visual Mastery
Complex concepts are made intuitive through visual representation, animations, and immediate feedback.

### Progressive Difficulty
Games start simple and gradually introduce complexity, ensuring students build confidence before tackling advanced concepts.

### Real Assessment
Dynamic interactions test actual understanding and problem-solving ability, not memorization or pattern recognition.
